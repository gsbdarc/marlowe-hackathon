# A1. Score Kev-27B before training

**Goal:** serve Kev-27B on one Yens H200 and measure how often it agrees with Jev. That score is the bar your own
fine-tuned teacher has to reach in A2.

| | |
|---|---|
| Where | Yens, 1 H200 |
| Data | the 1,000 test filings (2022 to 2026) with Jev's labels |
| Model | Kev-27B (`jaredpalmer/kev-27b@af0e6d5`), 51 GB of weights, built on Qwen3.8-27B |
| Time | about 15 minutes |

---

## Step 1: Set up on the Yens

Log in and work from the shared copy of this repository. `ssh yen.stanford.edu` puts you on an interactive node
(`yen1` to `yen5`), a full-size server where you can install and download directly.

```bash
ssh <sunet>@yen.stanford.edu
cd /scratch/shared/marlowe_hackathon
umask 002
source env/yens.sh
```
{: .yens }

`umask 002` keeps the files you create editable by the rest of the team. If Kev is not installed yet, install it once
(about 10 minutes, see [Before You Arrive]({{ '/setup/' | relative_url }})):

```bash
bash scripts/setup_kev.sh
```
{: .yens }

Copy the test filings into your own work folder, where the job reads them:

```bash
mkdir -p $WORK/data
cp data/test1000.jsonl data/test1000.parquet $WORK/data/
```
{: .yens }

## Step 2: Submit the job

```bash
mkdir -p logs
sbatch slurm/yens/advanced/a1_score_kev27b.slurm
```
{: .yens }

The job asks for one H200 (`-C GPU_MODEL:H200`), because Kev-27B's 51 GB of weights do not fit on an A40's 48 GB. It
starts a Kev server on the GPU, sends it the 1,000 test filings and scores the answers against Jev.

## Step 3: Read the scores

```bash
tail -f logs/adv-a1-kev27b-<jobid>.out
```
{: .yens }

The server log, `logs/kev-server-<jobid>.log`, shows the weights loading. When labeling finishes, the scores print at
the end of the job log. DARC's earlier run on an H200 agreed with Jev on about 95% of filings and about 87% of CEO
changes, at about 5 filings per second.

{: .checkpoint }
> **A1.** Post Kev-27B's agreement with Jev on CEO changes and its filings per second in Slack. Then put up a 🟩
> green sticky. 🟥 if you are stuck.

## If it fails

- **The job waits in the queue:** the Yens have two H200s. `squeue --me` shows why it is waiting.
- **`Kev server stopped`:** the server log says why. The first run downloads the 51 GB of weights into `$HF_HOME`,
  which takes longer than the scoring.
