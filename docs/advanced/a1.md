# A1. Fine-tune the teacher

**Goal:** fine-tune Kev-27B on Jev's labels, first on one H100 to see that it does not fit, then on all 8 H100s of one
node.

| | |
|---|---|
| Where | Marlowe, 1 GPU, then 1 node (8 H100s) |
| Data | `$DATA/train.jsonl`, 54,426 filings with Jev's soft labels |
| Model | Kev-27B as released, plus its base Qwen3.8-27B (both in the shared model cache) |
| Time | about 45 minutes |

---

## Why it does not fit on one GPU

A full fine-tune keeps about 16 bytes for every weight, and Kev-27B has about 25.5 billion:

| Kept during training | Bytes per weight | Kev-27B | Where it goes on 1 GPU | Per GPU on 8 GPUs |
|---|---|---|---|---|
| bf16 weights and gradients | 4 | 102 GB | the GPU | about 13 GB |
| fp32 master weights and optimizer state | 12 | 306 GB | node memory | about 38 GB |

An H100 has 80 GB, so the first row alone is too large for one GPU. With 8 GPUs, FSDP (fully sharded data parallel)
splits both rows eight ways, about 51 GB per GPU.

## Step 1: Try one GPU

```bash
cd $WORK
sbatch $ADV/slurm/a1_train_1gpu.slurm
```
{: .marlowe }

The job asks for one H100 and 480 GB of node memory, enough for the 306 GB Kev keeps there. Follow the log:

```bash
tail -f logs/adv-a1-1gpu-<jobid>.out
```
{: .marlowe }

Expect it to stop with `CUDA out of memory`. Check how full the GPU was when it failed:

```bash
tail -3 logs/gpu-<jobid>.csv
```
{: .marlowe }

## Step 2: One full node

```bash
sbatch $ADV/slurm/a1_train_8gpu.slurm
tail -f logs/adv-a1-8gpu-<jobid>.out
```
{: .marlowe }

`--gpus-per-node=8 --exclusive` takes the whole node, and `torchrun --nproc_per_node 8` starts one training process
per GPU. Look for `world=8` in the log, then a line every 10 optimizer steps; `loss` should fall. The run takes 50
steps of 16 records each. Check the memory on each GPU:

```bash
tail -8 logs/gpu-<jobid>.csv
```
{: .marlowe }

When the log ends with `saved .../runs/a1-8gpu`, that directory is your fine-tuned teacher. Read its speed and
memory:

```bash
$PY $ADV/scripts/step_times.py $WORK/runs/a1-8gpu
```
{: .marlowe }

## If it fails

- **The 8-GPU job runs out of memory, or stops with a `Traceback`:** post the last 20 lines of the log in Slack, and
  use DARC's fine-tuned teacher in [A2]({{ '/advanced/a2/' | relative_url }}).
- **The job waits in the queue:** `squeue --me` shows why. With the hackathon reservation set, it should start within
  minutes.
