# A4. Inference on the Yens

**Goal:** run the distilled Kev-4B on one Yen GPU, label filings with it, and score it against Jev.

| | |
|---|---|
| Where | Yens, 1 GPU |
| Data | the 1,000 test filings with Jev's labels, to score; any other filings to label, no labels needed |
| Model | the distilled Kev-4B from A3, compared with Kev-4B as released and with the teacher |
| Time | about 20 minutes |

This task is inference only: nothing trains. The model you trained on Marlowe now runs on hardware you can use any
day.

---

## Step 1: Score the student

From your clone of this repository on the Yens:

```bash
cd /scratch/users/$USER/marlowe-hackathon
source env/yens.sh
mkdir -p logs
sbatch slurm/yens/serve_and_label.slurm $WORK/runs/a3-student a3-student
```
{: .yens }

The job starts a Kev server with the student on one GPU, sends it the 1,000 test filings and scores the answers. If
the H200s are busy, add `-C GPU_MODEL:A40` after `sbatch`.

## Step 2: Compare

Score Kev-4B as released the same way, then put the three side by side:

```bash
sbatch slurm/yens/serve_and_label.slurm
```
{: .yens }

```bash
$PY scripts/score.py $WORK/results/kev-4b-zeroshot.jsonl $WORK/results/a3-student.jsonl \
  $WORK/advanced/kev27b_labels.jsonl
```
{: .yens }

| Row | Model |
|---|---|
| `kev-4b-zeroshot` | Kev-4B as released |
| `a3-student` | your distilled Kev-4B |
| `kev27b_labels` | the teacher, Kev-27B |

How much of the gap between Kev-4B and the teacher did distillation close? How many filings per second does the
student label, compared with the teacher on one GPU?

## Step 3: Label filings at scale

The same job labels any set of filings. To label every Item 5.02 filing with the student:

```bash
sbatch -t 1-00:00:00 slurm/yens/serve_and_label.slurm $WORK/runs/a3-student a3-all $DATA/item502_v1.parquet
```
{: .yens }

If the job reaches its time limit, submit it again: `label.py` skips filings already answered.
