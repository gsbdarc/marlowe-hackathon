# A3. Distill the student

**Goal:** train Kev-4B on the teacher's labels, then copy the distilled model to the Yens.

| | |
|---|---|
| Where | Marlowe, 1 GPU; then Globus to the Yens |
| Data | the training filings, with Kev-27B's labels (a probability for each option) as targets |
| Model | Kev-4B, merged to full weights, trained into the distilled student |
| Time | about 45 minutes |

---

## Step 1: Train the student

```bash
cd $WORK
sbatch $ADV/slurm/a3_distill_1gpu.slurm
```
{: .marlowe }

If A2 did not finish, use DARC's teacher labels:

```bash
TEACHER_LABELS=$LABELS_FALLBACK sbatch $ADV/slurm/a3_distill_1gpu.slurm
```
{: .marlowe }

The job first runs `scripts/make_student_data.py`. For each training filing, it replaces Jev's probabilities with the
teacher's, so the student learns what Kev-27B would answer. A filing the teacher calls "not a CEO change" keeps only
the status question. The log starts with the number of records it wrote, about 54,000.

Then Kev-4B trains on those records on one H100: 100 steps of 16 records, the same settings as the Kev-4B fine-tune
in the other tracks. Kev-4B fits on one GPU, so there is no need for more.

```bash
tail -f logs/adv-a3-distill-<jobid>.out
```
{: .marlowe }

When the log ends with `saved .../runs/a3-student` and its size (about 8 GB), that directory is the distilled model.

## Step 2: Copy it to the Yens

Use the Globus CLI as on [Moving Data with Globus]({{ '/globus/' | relative_url }}), with these paths:

| From (Marlowe) | To (Yens) |
|---|---|
| `$WORK/runs/a3-student/` (recursive) | `/scratch/users/<sunet>/ceo-turnover/runs/a3-student/` |
| `$WORK/a2/kev27b_labels.jsonl` | `/scratch/users/<sunet>/ceo-turnover/advanced/kev27b_labels.jsonl` |

The teacher's labels come too, so you can compare teacher and student in A4. If your A3 did not finish, copy DARC's
distilled model, `$STUDENT_FALLBACK`, instead.
